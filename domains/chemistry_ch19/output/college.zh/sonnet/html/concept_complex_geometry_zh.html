复数的几何表示

定义：复数 $z = a + bi$ 可以用平面上的点 $(a, b)$ 表示，这个平面称为复平面（Argand 平面），实部对应横轴，虚部对应纵轴。复数的模 $|z| = \sqrt{a^2 + b^2}$ 表示该点到原点的距离；辐角 $\theta = \arg(z)$ 表示该点与原点的连线相对于正实轴的夹角。任何非零复数都可以写成极坐标形式：

$$z = r(\cos\theta + i\sin\theta) = re^{i\theta}$$

其中 $r = |z|$，这就是欧拉公式给出的极坐标表示。

复数运算的几何意义十分直观：加法对应向量相加，遵循平行四边形法则；乘法则同时涉及“缩放”与“旋转”——两个复数相乘时，模相乘、辐角相加：

$$z_1 z_2 = r_1 r_2\, e^{i(\theta_1+\theta_2)}$$

这一结论可由欧拉公式直接证明，是理解复数几何意义的核心定理：乘以一个复数，就是对平面上的向量做一次“旋转 + 缩放”的复合变换。

例题：设 $z_1 = 1+i$，$z_2 = \sqrt{3}+i$。化为极坐标：$z_1 = \sqrt{2}(\cos45^\circ+i\sin45^\circ)$，$z_2 = 2(\cos30^\circ+i\sin30^\circ)$。于是

$$z_1 z_2 = 2\sqrt{2}\,(\cos75^\circ+i\sin75^\circ)$$

几何上看，乘以 $z_2$ 相当于把 $z_1$ 对应的向量放大 2 倍，并逆时针旋转 $30^\circ$。

应用：这一几何直觉在工程与物理中广泛使用。交流电路分析中，阻抗和电压用复数表示，乘以 $e^{i\theta}$ 相当于引入一个相位延迟，无需重新展开三角恒等式；信号处理中的相量（phasor）旋转同样依赖复平面的几何图像，而不是代数运算本身。

练习：求满足 $|z-2| = |z+2i|$ 的所有点 $z$ 构成的图形。（提示：这是复平面上到两个定点 $2$ 与 $-2i$ 距离相等的点的集合，其几何轨迹是连接这两点线段的垂直平分线。）
