Core Electrons

Core electrons are the electrons that occupy the fully filled inner shells of an atom — every electron that is not in the outermost (valence) shell. They sit close to the nucleus, are held tightly by strong electrostatic attraction, and do not participate in ordinary chemical bonding. For an atom with electron configuration written in shells, the core is everything except the last shell: sodium ($Z=11$), configured as $1s^2\,2s^2\,2p^6\,3s^1$, has ten core electrons ($1s^2\,2s^2\,2p^6$) and one valence electron ($3s^1$). The core electron count for a main-group element equals the atomic number of the nearest preceding noble gas.

Worked example. Consider chlorine ($Z=17$): $1s^2\,2s^2\,2p^6\,3s^2\,3p^5$. The preceding noble gas is neon ($Z=10$), so chlorine has 10 core electrons and 7 valence electrons. This is exactly what the shorthand notation $[\text{Ne}]\,3s^2\,3p^5$ expresses: $[\text{Ne}]$ is a stand-in for the 10 core electrons, and only the valence configuration is written out explicitly. This shorthand isn't just a writing convenience — it reflects a real chemical fact: the core electrons are essentially inert to reactions, so chemists can safely ignore them when reasoning about bonding.

Problem-solving application. The practical payoff of separating core from valence electrons is that it lets you predict reactivity and bonding capacity quickly, without writing full configurations. Suppose you need the number of core and valence electrons for phosphorus ($Z=15$) and calcium ($Z=20$). For phosphorus, the nearest lower noble gas is neon ($Z=10$), so there are 10 core electrons and $15-10=5$ valence electrons — consistent with phosphorus forming compounds like $\text{PCl}_3$ and $\text{PCl}_5$. For calcium, the nearest lower noble gas is argon ($Z=18$), giving 18 core electrons and $20-18=2$ valence electrons, matching calcium's typical $+2$ oxidation state ($\text{Ca}^{2+}$). This same logic explains periodic trends: because core electrons shield valence electrons from the full nuclear charge, elements with more core shells (further down a group) have valence electrons that are held less tightly, which is why atomic radius increases and ionization energy decreases down a group. Recognizing the core/valence split is therefore a fast, reliable shortcut for predicting an element's typical ion charge, bonding behavior, and position-dependent reactivity trends.
