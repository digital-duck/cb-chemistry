Ion Electron Configuration

When an atom gains or loses electrons to form an ion, its electron configuration changes in a predictable way — but the rule is not simply "add or remove electrons from wherever they last went in." For anions (negatively charged ions), added electrons fill the next available orbital following the standard order, extending the neutral atom's configuration. For cations (positively charged ions), electrons are always removed first from the orbital with the highest principal quantum number $n$, and among orbitals with the same $n$, from the one with the highest energy — which for transition metals means $ns$ electrons are lost before $(n-1)d$ electrons, even though $4s$ filled before $3d$.

Worked example. Consider iron, $\text{Fe}$, with neutral configuration $[\text{Ar}]3d^{6}4s^{2}$. To form $\text{Fe}^{2+}$, iron loses two electrons. A common mistake is to remove them from $3d$ because it was filled last in the building-up order. But the correct rule is: remove electrons from the highest $n$ shell first. Since $4s$ has $n=4$ and $3d$ has $n=3$, the two $4s$ electrons leave first, giving $\text{Fe}^{2+}: [\text{Ar}]3d^{6}$. Forming $\text{Fe}^{3+}$ removes one more electron, this time from $3d$ (since $4s$ is now empty), giving $[\text{Ar}]3d^{5}$ — a configuration with five unpaired electrons in five separate $d$ orbitals, which is unusually stable and explains why $\text{Fe}^{3+}$ is a common, robust oxidation state.

For an anion example, oxygen ($[\text{He}]2s^{2}2p^{4}$) gains two electrons to fill its $2p$ subshell completely, forming $\text{O}^{2-}: [\text{He}]2s^{2}2p^{6}$, isoelectronic with neon.

Problem-solving application. This rule matters whenever you need to predict magnetic behavior, color, or reactivity of transition-metal ions. To determine the configuration of any cation: (1) write the neutral atom's configuration in filling order, (2) identify the electrons with the highest $n$, (3) remove electrons starting there, working down in $n$ if needed. Try it for $\text{Cu}^{2+}$: neutral copper is $[\text{Ar}]3d^{10}4s^{1}$, so removing two electrons takes the single $4s$ electron and one $3d$ electron, giving $[\text{Ar}]3d^{9}$ — not $3d^{10}4s^{-1}$, which is nonsensical, and not $3d^{8}4s^{2}$, which violates the highest-$n$-first rule.
